# Bard Mutator Lab

Development lab for [`jacksleight/statamic-bard-mutator`](../statamic-bard-mutator), pulled in over a composer path repository so edits in the package are live here.

Runs at http://statamic-bard-mutator--lab.test/ (Herd parks `~/Packages`). Log in at `/!/skip/admin`.

A `tests` collection with an entry per feature, each with its own scoped plugin, blueprint and template, and a `demos` collection that runs the marketplace slides' plugin code for real.
